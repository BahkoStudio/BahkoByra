# Kvist: Content

Byråns EGET content, en mapp per uppgift. Kundernas content (Bromma m.fl.) bor i
`2-kunder/kunder/<kund>/`, inte här.

| Mapp/fil | Vad |
|---|---|
| `instagram_engine.md` | IG-rutinen för @bahkobyra |
| `ig/` | Kontentplan, mallar, media och veckans paket |
| `dm/` | DM-öppnare och systemprompten för DM |
| `email/` | Välkomstmejl, sekvens, nyhetsbrev |
| `cold-call/` | Ringlistor och ringmanus |
| `reels/` | Reelmanus |
| `guider/` | Gratisguider (leadmagneter) |
| `apps-script/` | Dagsloggens Google Apps Script |

Skills: `/ig-karusell`, `/bahko-reel`, `/bahko-reklamfilm`, `/reel` (manus).
Strategin som filtrerar allt content (Spelvärlden, Säsongen) bor i kommandocentralen,
se `docs/bahko_os.md`.

⚠ Inte samma sak som `bahkobyra/` högst upp i repot, som är kundernas sajtkod.
